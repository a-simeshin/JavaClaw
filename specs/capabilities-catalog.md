# Enterprise JavaClaw: Каталог возможностей

> Каждая возможность описана простым языком, указан источник (откуда берём идею), текущий статус в JavaClaw и приоритет.
>
> **Приоритеты:** P0 = must have для запуска, P1 = нужно сразу после, P2 = масштабирование, P3 = расширение, P4 = nice to have

| 15.2.4 | **Custom roles**                    | Администратор может создать свою роль с произвольным набором прав                                              | **P2**    |
| 15.2.5 | **Group-based assignment**          | Роли назначаются через группы (из LDAP/OIDC groups claim) — не надо назначать каждому вручную                  | **P4**    |

**Предустановленные роли:**

|      Роль      |         Описание         |                                              Ключевые права                                              |
|----------------|--------------------------|----------------------------------------------------------------------------------------------------------|

### 15.7 Архитектура доступа (как это работает внутри)

```
┌─────────────────────────────────────────────────────────┐
│                     HTTP Request                         │
│              (JWT token from SSO/OIDC)                   │
└─────────────────┬───────────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────────┐
│            Spring Security Filter Chain                   │
│  1. JWT validation (корп. IdP)                           │
│  2. User resolution (JWT → User entity в БД)             │
│  3. Role/permission loading (из БД или JWT claims)       │
└─────────────────┬───────────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────────┐
│              Authorization Layer                          │
│                                                           │
│  @PreAuthorize("hasPermission('skill:use:summarize')")   │
│  @PreAuthorize("hasRole('ADMIN')")                       │
│  @PreAuthorize("hasPermission('conversation:read:' + #id)")│
│                                                           │
│  PermissionEvaluator:                                    │
│  - Проверяет role → permissions mapping                  │
│  - Проверяет resource ownership (мой диалог?)            │
│  - Проверяет skill/MCP allowlist для роли                │
└─────────────────┬───────────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────────┐
│              Business Logic                               │
│                                                           │
│  ChatService:                                            │
│  - conversationId = "user-{userId}-{agentId}-{seq}"      │
│  - Фильтрация tools по permissions пользователя          │
│  - Фильтрация skills по allowlist роли                   │
│  - Фильтрация MCP servers по visibility + role           │
│                                                           │
│  AgentToolFilter:                                        │
│  - Перед вызовом агента: собрать только разрешённые tools │
│  - tool.riskLevel <= user.maxAllowedRiskLevel            │
│  - skill.visibility allows user.role                     │
│  - mcpServer.access allows user.role                     │
└─────────────────────────────────────────────────────────┘
```

### 15.8 Схема БД (ключевые таблицы)

```sql
-- Пользователи
CREATE TABLE users (
    id            UUID PRIMARY KEY,
    external_id   VARCHAR(255) UNIQUE,  -- ID из SSO/OIDC (sub claim)
    login         VARCHAR(100) UNIQUE NOT NULL,
    email         VARCHAR(255),
    display_name  VARCHAR(255),
    avatar_url    VARCHAR(500),
    active        BOOLEAN DEFAULT TRUE,
    created_at    TIMESTAMP NOT NULL,
    last_login_at TIMESTAMP
);

-- Роли
CREATE TABLE roles (
    id          UUID PRIMARY KEY,
    name        VARCHAR(50) UNIQUE NOT NULL,  -- ADMIN, POWER_USER, USER, VIEWER
    description VARCHAR(255),
    built_in    BOOLEAN DEFAULT FALSE,        -- предустановленная роль
    priority    INT NOT NULL                  -- для иерархии: 100=ADMIN, 50=POWER_USER, 10=USER, 1=VIEWER
);

-- Права (permissions)
CREATE TABLE permissions (
    id   UUID PRIMARY KEY,
    code VARCHAR(100) UNIQUE NOT NULL  -- 'chat:send', 'skill:use:*', 'mcp:manage', 'admin:users'
);

-- Роль ↔ Права (many-to-many)
CREATE TABLE role_permissions (
    role_id       UUID REFERENCES roles(id),
    permission_id UUID REFERENCES permissions(id),
    PRIMARY KEY (role_id, permission_id)
);

-- Пользователь ↔ Роли (many-to-many)
CREATE TABLE user_roles (
    user_id UUID REFERENCES users(id),
    role_id UUID REFERENCES roles(id),
    PRIMARY KEY (user_id, role_id)
);

-- Доступ к скиллам по ролям
CREATE TABLE skill_access (
    id         UUID PRIMARY KEY,
    skill_name VARCHAR(100) NOT NULL,
    role_id    UUID REFERENCES roles(id),
    allowed    BOOLEAN DEFAULT TRUE,
    UNIQUE (skill_name, role_id)
);

-- Доступ к MCP-серверам
CREATE TABLE mcp_server_access (
    id            UUID PRIMARY KEY,
    mcp_server_id VARCHAR(100) NOT NULL,
    visibility    VARCHAR(20) NOT NULL,  -- 'global', 'role_restricted', 'personal'
    owner_id      UUID REFERENCES users(id),  -- для personal серверов
    role_id       UUID REFERENCES roles(id)   -- для role_restricted
);

-- Доступ к MCP-инструментам (тонкая настройка)
CREATE TABLE mcp_tool_access (
    id            UUID PRIMARY KEY,
    mcp_server_id VARCHAR(100) NOT NULL,
    tool_name     VARCHAR(100) NOT NULL,
    role_id       UUID REFERENCES roles(id),
    blocked       BOOLEAN DEFAULT FALSE,  -- true = инструмент заблокирован для этой роли
    risk_level    VARCHAR(20) DEFAULT 'safe'  -- 'safe', 'moderate', 'dangerous'
);

-- Привязка диалогов к пользователям
CREATE TABLE conversation_access (
    id              UUID PRIMARY KEY,
    conversation_id VARCHAR(255) NOT NULL,
    user_id         UUID REFERENCES users(id),
    access_level    VARCHAR(20) NOT NULL,  -- 'owner', 'read_write', 'read_only'
    UNIQUE (conversation_id, user_id)
);

-- Доступ к агентам по ролям
CREATE TABLE agent_access (
    id       UUID PRIMARY KEY,
    agent_id VARCHAR(100) NOT NULL,
    role_id  UUID REFERENCES roles(id),
    allowed  BOOLEAN DEFAULT TRUE,
    model_override VARCHAR(100),   -- другая модель для этой роли
    quota_per_day  INT,            -- лимит запросов в день
    UNIQUE (agent_id, role_id)
);

-- Аудит-лог
CREATE TABLE audit_log (
    id            UUID PRIMARY KEY,
    user_id       UUID REFERENCES users(id),
    action        VARCHAR(50) NOT NULL,   -- 'chat:send', 'skill:invoke', 'mcp:call', 'admin:config_change'
    resource_type VARCHAR(50),            -- 'conversation', 'skill', 'mcp_tool', 'user'
    resource_id   VARCHAR(255),
    details       JSONB,                  -- доп. данные (параметры, результат)
    ip_address    VARCHAR(45),
    created_at    TIMESTAMP NOT NULL
);
```
