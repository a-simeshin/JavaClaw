## Notes

- `OFFSET ? LIMIT ?` syntax (ConversationQueryService) is supported by both PostgreSQL and SQLite — classified **portable**.
- `CURRENT_DATE` (AgentQuotaRepository) is ANSI SQL — portable on its own, but co-located with `now()` in the same query so the whole statement is dialect-sensitive.
- `COALESCE` is ANSI SQL and supported by both dialects — portable.
- Spring Data JDBC `@Query` annotations (unlike JPA) are plain SQL, not JPQL, so all rules above apply equally.
- Task repositories (`TaskRepository`, `TaskExecutionRepository`, `ApprovalRequestRepository`, `RecurringTaskRepository`) use only derived queries — no raw SQL found.
