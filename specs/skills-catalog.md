## Формат скилла (стандарт из OpenClaw)

Каждый скилл — markdown-файл `SKILL.md` с YAML frontmatter:

```markdown
---
name: skill-name
description: >
  Когда использовать этот скилл. Use when...
  NOT for: ...
---

# Skill Name

## Инструкции для агента

[Подробные инструкции что делать, какие команды вызывать, формат ввода/вывода]

## Примеры

[Примеры использования]
```

В JavaClaw скиллы хранятся в PostgreSQL (virtual_files), загружаются через SkillsTool, управляются через Skill management tool (4.9a) или Admin/User UI.
